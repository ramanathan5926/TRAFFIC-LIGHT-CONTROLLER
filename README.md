# Traffic Light Controller using Verilog HDL

This project implements a **Traffic Light Controller** using **Verilog HDL** based on a **Finite State Machine (FSM)**.  
The controller operates three traffic signals (RED, GREEN, YELLOW) in a fixed sequence with clock-based timing.

The design is simulated using **Icarus Verilog** and verified through waveform analysis in **GTKWave**.

**States:** RED → GREEN → YELLOW → RED  
**Concepts:** FSM, counters, sequential & combinational logic
